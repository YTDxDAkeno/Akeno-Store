# Build-Artefakte

- `akeno-gaming-hub-host.zip` enthält den Quellcode und die Buildskripte.
- `akeno-hub-linux-x86_64` ist der native Linux-Katalog. Er benötigt SDL2.
- `akeno-hub-target-objects.zip` enthält die separat kompilierten PS5-Zielobjekte aus dem vorigen Entwicklungsdurchlauf. Diese Objekte dienen der Link- und ABI-Prüfung.

Das installierbare PS5-Paket steht aus. Anleitung und aktueller Stand befinden sich in `platform/ps5/README.md` im Quellcode.
